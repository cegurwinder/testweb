# Aurora AI — Premium Landing Page

A polished dummy SaaS/AI landing page built with Next.js. Ready for GitHub and Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Create a new GitHub repository.
2. Upload all files from this project.
3. In Vercel, choose **Add New > Project**.
4. Import the GitHub repository.
5. Vercel should detect Next.js automatically.
6. Click **Deploy**.

## Customize

Edit `app/page.js` for text and sections.
Edit `app/globals.css` for colors, spacing, effects and responsive design.
